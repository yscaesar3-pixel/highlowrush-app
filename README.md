# ハイローラッシュ（HighLowRush）プロトタイプ

`HighLowRush_complete_spec.md` に基づく、単一HTMLファイルのプロトタイプです。
既存アプリ（ぐるくじ 等）と同じく「単一HTML → PWA → Capacitor」の流れを想定しています。

## 今回できていること（仕様どおり動作）

- ホーム／シングル（チュートリアル・ゲーム・でたカード・けっか・シェア画像プレビュー）
- みんなであそぶ（せってい画面・ゲーム・でたカード）
- せってい（ゲーム別アコーディオン・おと/しんどう・そのほか）／このアプリについて／プライバシー・利用規約（プレースホルダー）
- ゲームロジック
  - シングル: 52枚使い切り→自動まぜなおし→○しゅうめ！の周回、streak引き継ぎ、履歴は周期ごとリセット
  - シングル確率: 実残り山札から↓/おなじ/↑を整数%で計算し合計100%
  - マルチ: 通常（52 or ジョーカーで54、山札タップ引き）／エンドレス（独立フルプール抽選、∞表示）／ジョーカー（ジョーカー個別カウント）
  - でたカード一覧（♦→♥→♠→♣ × A〜K のマトリクス、現在カード太枠、既出は半透明、エンドレスは×N表示）
- 保存: localStorage（BEST・おと・しんどう・各かくりつ/でたカード設定・チュートリアル済みフラグ・マルチ4設定）。壊れた値は個別に初期値へフォールバックし他の項目は保持
- 広告: 全対象画面下部に固定の予約スペース（読み込み中/失敗でもレイアウトが動かない設計）。「このアプリについて」等はバナーなし
- サウンド/振動: 設定に応じて有効/無効、テスト音・テスト振動は出さない
- 戻る操作: 明示ボタンのみ。ブラウザのスワイプ戻る相当は使っていません

## プロトタイプゆえに仮実装になっている部分（後で差し替え前提）

| 項目 | 現状 | 本番での差し替え予定 |
|---|---|---|
| アプリアイコン／ロゴ／背景／シェア用1080x1080画像 | コードで描画した簡易プレースホルダー | いただいた画像アセットに差し替え |
| カード裏面の中央ロゴ | 「H」の文字のみ | 白抜きロゴ画像に差し替え |
| 効果音 | Web Audioで生成した簡易ビープ音 | 本番SFXファイルに差し替え |
| 振動 | `navigator.vibrate`（Webブラウザ限定） | Capacitor Hapticsプラグインに置き換え |
| バナー広告 | 灰色のプレースホルダー枠 | Capacitor AdMobプラグイン（`app_id_ios: ca-app-pub-8174756915786797~3111467770` / banner: `.../4454826263`）に接続 |
| 共有（シェア） | `navigator.share` があれば使用、なければトースト表示 | Capacitor Share / システム共有シートに接続 |
| お問い合わせメール | `mailto:` リンク | Capacitor製 or ネイティブのメール作成画面に接続（宛先/バージョン情報は自動付与済みロジックを流用可） |
| レビュー導線 | トースト表示のみ | `SKStoreReviewController` または App Store review URL |
| プライバシー/利用規約 | URL未定のためプレースホルダー文言 | `privacy_url` / `terms_url` 確定後にWebView実装 |
| QRコード | 四角の枠のみ（「QR」表示） | 実際のQR生成ライブラリ + App Store URL |
| 左端スワイプ戻る無効化 | HTML単体では未対応（ブラウザ機能） | Capacitorラップ時にネイティブ設定で無効化 |
| 画面の向き固定・iPad非対応 | HTML単体では未対応 | Capacitor / Xcode 側のプロジェクト設定で対応 |

## 実装上の解釈（仕様に明記がなく、整合的に判断した箇所）

1. **マルチプレイヤーの設定変更確認ダイアログ**: 「エンドレス」「ジョーカー」を試合中に変更した場合のみ、山札/履歴が消える旨の確認ダイアログを表示します。「でたカードをみる」「かくりつをみる」は表示切り替えのみのため即時反映です。
2. **エンドレスの確率計算**: 現在カード自身も含めたフルプール（52 or 54枚）を毎回の母数として、↓/おなじ/↑（+ジョーカー）を計算しています（履歴に依存せず一定）。

## 自動プレイテスト（`test/playtest.js`）

`index.html` と全く同じコードを jsdom 上で実際に動かし、内部状態を見ながら「必ず正解する手」を選んで自動プレイするテストスクリプトです。人力では確認しづらい部分（51枚消化→自動まぜなおし、周回99+、999+表示など）を検証しています。

実行方法:
```
cd test
npm install
node playtest.js
```

このテストで見つけて修正した不具合:
- **現在の連勝表示に「！」が抜けていた** — `○れんしょう！`と表示すべきところが`○れんしょう`になっていました（さいこうきろく表示側は仕様通り「！」なしのままです）。

その他、以下を自動プレイで確認済みです:
- シングル: 51枚使い切り→自動まぜなおし→2しゅうめ・3しゅうめの遷移、streak引き継ぎ、周期ごとのhistoryリセット、確率表示の合計が常に100%、999+/99+の表示丸め、はずれ時に結果画面へ「ざんねん！」等を出さずに遷移、手動ホーム帰還でBEST更新なし
- マルチ: 事前設定画面必須遷移、ジョーカーON時54枚、山札使い切り時のパネル表示→まぜなおし確認→再開、ジョーカーON時の4項目確率が合計100%

## 次にやること（提案）

2. 問題なければ、いつものPWA化→Capacitorラップの手順に進めます（`capacitor.config.json`、`ios/`プロジェクト生成、AdMob/Haptics/Shareプラグイン導入など）。
3. アイコン・ロゴ・背景・シェア画像が揃ったら、該当箇所（コメントで `placeholder` と明記した部分）を差し替えます。
